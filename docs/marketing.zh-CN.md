## 30 字产品介绍

本地优先的 Windows 成长助手，用任务、日历、复盘、行业情报和学习计划，把长期目标落实到每一天。

## 100 字产品介绍

Personal Growth Assistant 是一款本地优先的 Windows 桌面应用。它不只是待办清单：你可以安排任务与重复日程、生成晨间简报、接收原生提醒、完成每日复盘，聚合可信行业信息，并把学习目标拆成课程、测验和间隔复习。核心功能无需账号、网络或 AI；数据首先保存在你的电脑上。

## GitHub / Product Hunt 风格介绍

你缺的可能不是更多目标，而是一个能把目标送到“今天”的系统。

Personal Growth Assistant 将任务、日历、复盘、行业情报和学习路径连成一个闭环。它能在本地生成晨间简报，提醒你真正重要的事；也能把零散信息变成可执行任务，把长期学习变成每日课程与复习节奏。应用默认无账号、无遥测、无自动云同步，AI 只是可选择的增强能力。

现在，它以 Apache 2.0 许可证开源。

它把任务、日历、晨间简报、复盘、行业情报和学习计划放到一个 Windows 桌面应用里。核心功能离线可用，数据默认留在本机，没有账号系统，也没有产品遥测。你可以用它安排重复任务、接收原生提醒、聚合可信来源、做客观测验和间隔复习；需要时，再开启隔离运行的 Codex 智能建议。

## 截图配文

- **今日**：一眼看到今天真正重要的事，时间预算与晨间简报就在下方。
- **日历**：日、周、月自由切换，重复任务和长标题也保持清晰。
- **复盘**：不靠情绪打分，用完成、延期和偏差找到下一次改进动作。
- **行业情报**：信息不止被收藏，它可以被判断、去重，并变成下一步行动。
- **学习**：目标、知识节点、课程、测验和复习，组成一条看得见的成长路径。

## 使用边界

- 不宣传“绝对安全”“完全匿名”或“AI 永不出错”。
- 不把任务建议表述为医疗、法律、财务等专业决策。
- 展示截图时使用仓库内的合成演示数据，不使用真实账号、任务或私有来源。
- 当前安装包未商业签名，应如实提示 SmartScreen 与 SHA-256 校验步骤。
